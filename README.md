# 라이브 판매 감지 (폰)

그립·클릭메이트 방송 화면의 판매 알림을 읽어 아래쪽에 판매 수·추정 매출을 보여 주는 폰용 스크립트입니다. (읽기 전용, 방송 화면을 조작하지 않음)

## 설치 (안드로이드 Firefox + Violentmonkey)
아래 링크를 폰 Firefox에서 열고 **설치**를 누르세요.

https://raw.githubusercontent.com/Jdragon007/live-watch-phone/main/live-watch-phone.user.js

새 버전은 Violentmonkey가 자동으로 받습니다.

> 이 파일은 비공개 개발 저장소의 PC 확장 원본에서 자동으로 만들어집니다. 여기서 직접 고치지 마세요.
